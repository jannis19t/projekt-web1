# Valo Hub

Fanouškovský web s přehledem agentů, map a zbraní ze hry VALORANT.
Vytvořeno jako cvičný projekt v HTML a CSS.

## Stránky

- `index.html` – úvodní stránka s hero sekcí, statistikami a výběrem agentů
- `agents.html` – seznam všech agentů rozdělený podle rolí
- `maps.html` – přehled všech map
- `weapons.html` – přehled zbraní (TODO)

## Použité technologie

- HTML5
- CSS3 (Grid, Flexbox, CSS proměnné)
- [Google Fonts](https://fonts.google.com/) – Barlow, Barlow Condensed
- [Font Awesome](https://fontawesome.com/) – ikony v patičce

## Struktura barev

Barvy jsou definované jako CSS proměnné v `:root` v `style.css`:

- `--bg-color` – hlavní tmavé pozadí
- `--akcent` – červená akcentní barva
- `--dualista`, `--strazce`, `--kontroler`, `--iniciator` – barvy podle rolí agentů

## Poznámky

- Projekt není oficiálně spojen s Riot Games
- Loga a obrázky agentů/map jsou zástupné, určené k nahrazení vlastními assety
- Udělána menší responsivita na mobil.
